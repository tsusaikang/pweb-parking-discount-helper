# pweb-parking-discount-helper

> pweb.kr 주차 할인등록 화면에서 "**0원까지 할인권을 몇 장 더 넣어야 하는지**"를 계산해 주는 도구
> (정식 명칭 "pweb 주차할인 계산기" · 북마크명 "할인계산")

## 이게 뭔가요

`pweb.kr` 기반 주차 할인등록 화면은 차량을 조회하면 입차시각과 경과시간만 보여줍니다.
정작 필요한 "**지금 주차권을 얼마나 더 적용해야 정산이 0원으로 끝나는지**"는 알려주지 않습니다.
예전 건물 자체 시스템엔 있던 값인데 사라져서, 매번 암산해야 했습니다.

이 도구는 그 숫자를 되살립니다. 그게 전부입니다.

## 무엇을 해주나

- **부족분 계산 + 최소비용 조합 추천** — 아직 0원이 아니면, 얼마가 부족한지와 그걸 가장 싸게 채우는 할인권 조합을 추천합니다. 딱 맞추지 않고 출차 여유 15분까지 덮는 조합을 골라 안전하게 넘깁니다.
- **0원 상태 실시간 카운트다운** — 이미 0원이면 "앞으로 얼마나 여유가 있는지 / 몇 시까지 0원인지"를 1초마다 갱신해 보여줍니다.
- **초과 적용 안내** — 이미 0원인데 필요 이상으로 비싸게 적용했으면 "N원 절약 가능 — 무엇을 빼고 무엇을 넣을지"를 알려줍니다(자동으로 빼거나 넣지는 않습니다).
- **모바일 지원** — 폰에서는 화면 오른쪽에 좁은 세로 도크로 떠서 할인 버튼을 가리지 않고, 글씨를 키워 보정합니다(실제 주 사용처가 폰).

## 두 가지 사용 방법

- **방법 A — 자동 실행(권장)**: Tampermonkey(PC Edge/Chrome, Android Edge/Firefox) 또는 iPhone Safari의 "Userscripts" 앱에 `pweb-parking-calc.user.js`를 설치하면, 할인등록 화면을 열 때 패널이 저절로 뜹니다.
- **방법 B — 북마클릿**: 확장을 설치할 수 없는 환경(회사 PC, Android Chrome)용. 북마크 "할인계산"을 누르면 패널이 뜨고, 다시 누르면 닫힙니다.

둘 다 매번 `app.js`를 받아 실행하므로 항상 최신 버전으로 동작합니다.

## 왜 이런 모양인가

할인등록 데이터는 로그인해야 보이므로 다른 도메인의 웹페이지에서는 읽을 수 없습니다(CORS·쿠키 미공유).
데이터를 읽을 수 있는 곳은 로그인된 그 페이지 안뿐입니다. 그래서 그 페이지 위에서 도는 북마클릿·유저스크립트 형태입니다.

- 이미 로그인해 열어둔 페이지 위에서만 동작합니다.
- 페이지가 이미 불러온 값만 읽습니다. **외부 전송·저장·자동 로그인 없음.**
- **주차권을 실제로 적용하지 않습니다.** 운영 중인 실제 시스템이라 잔여량에서 돈이 빠지므로, 오로지 화면의 값을 읽어 계산만 합니다.

## 어느 건물이든 동작

주소 앞부분(예: `a23021`)은 건물 번호일 뿐, 도메인을 하드코딩하지 않습니다.
`pweb.kr` 할인등록 화면을 쓰는 곳이면 어느 건물에서든 동작합니다(전국 수천 개 현장이 같은 플랫폼).
건물마다 구조가 달라 계산이 어긋날 수 있는 경우엔, 스스로 감지해 멈추고 "사용 금지"를 표시합니다 — 틀린 숫자보다 아무것도 안 보여주는 편이 낫기 때문입니다.

## 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 설치·사용 안내 페이지(공개: <https://tsusaikang.github.io/pweb-parking-discount-helper>). 북마클릿 로더를 런타임에 `javascript:` URL로 조립하고, 문서 끝에 버전 이력이 있습니다. |
| `app.js` | 계산기 본체(유일한 로직 원본). 북마클릿 로더와 유저스크립트가 매번 이 파일을 받아 실행합니다. |
| `pweb-parking-calc.user.js` | Tampermonkey/Userscripts용 래퍼. `app.js`를 로드할 뿐 로직은 없습니다. |
| `version.json` | 설치 페이지 배지용 버전. `app.js`의 `VERSION`·`index.html` 이력과 같은 semver입니다. |
| `CLAUDE.md` · `HISTORY.md` · `HANDOVER.md` | 작업 규칙·현행 사양 / 결정 경위·실측 사례 / 지금 상태·다음 할 일 (운영 문서). |

## 설치

<https://tsusaikang.github.io/pweb-parking-discount-helper> 에 접속해(또는 `index.html`을 브라우저로 열어) 안내를 따르면 됩니다(방법 A는 확장 설치 후 초록 버튼으로 스크립트 설치, 방법 B는 PC 즐겨찾기 바로 드래그·폰은 코드 복사 후 북마크 URL 교체).
